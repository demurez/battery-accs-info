# Battery Monitor

Нативное приложение для Windows 11 x64 на C++20, Win32, Direct2D и DirectWrite.

## Запуск

Откройте `dist\BatteryMonitor.exe`. Храните папку `dist\devices` рядом с программой. Для запуска достаточно системных компонентов Windows. Параметр `--tray` запускает приложение свёрнутым в трей.

- При наведении на значок в трее появляется сводка по всем устройствам: заряд, подключение, статус и время последнего наблюдения 100%. Клик по значку открывает мини-окно в системной теме с кнопками обновления и перехода в основное приложение. Escape или щелчок снаружи закрывает мини-окно. Закрытие окна сворачивает приложение в трей. В меню значка есть команда «Выход».
- Кнопка «Обновить» или F5 запускает опрос. Фоновый опрос выполняется раз в две минуты, а при полном отсутствии показаний — раз в минуту. При переподключении HID-приёмника и после выхода ПК из сна приложение обновляет данные досрочно.
- Сводка появляется в Центре уведомлений рядом с календарём (клик по часам или Win+N). Приложение регистрирует ярлык Battery Monitor в меню «Пуск» текущего пользователя. В заголовке сводки видны уровни устройств, внутри — отдельные полосы заряда. Звёздочка помечает последнее известное показание отключённого устройства. При изменении показаний одна тихая запись обновляется без звука и всплывающего баннера. Меню трея позволяет отключить сводку или показать её снова. Показ зависит от настроек уведомлений Windows.

После полного заряда приложение отмечает первое наблюдение работы на батарее. Если устройство сообщает только уровень, начало определяется по первому снижению со 100%. Счётчик суммирует интервалы между доступными показаниями, пока устройство работает на батарее. Пропуски опроса, зарядка и периоды с закрытым приложением не добавляются. Начало цикла, накопленное время и последняя полная зарядка сохраняются для каждого профиля. Подтверждённую зарядку сопровождает мягкая пульсация с учётом настройки анимаций Windows.

## Подключённые устройства

| Устройство | Как читается заряд |
| --- | --- |
| VXE R1 NearLink | Запрос заряда по HID. Поддерживаются приёмник и USB-кабель. |
| Razer Barracuda X (2021) | Запрос напряжения по Airoha RACE через донгл `1532:054E`. Процент рассчитывается по приближённой кривой Li-ion. |
| Flydigi Direwolf 4 | Battery Monitor поддерживает чтение через свой USB-фильтр, когда подписанный пакет установлен. Без него выполняется проверка Windows.Gaming.Input и XUSB. Штатный XUSB в испытании вернул `BATTERY_TYPE_WIRED` без уровня заряда. |

Входные параметры Airoha и кривая напряжения также сверены с [описанием протокола Barracuda X](https://github.com/mehdibouchami/razer-barracuda-x-battery/blob/main/src/Protocol.cs). Приближение проверено на ответе донгла, точность калибровки версии 2021 отдельно не измерялась.

Формат ответа XUSB сверён с [HIDMaestro](https://github.com/hifihedgehog/HIDMaestro/issues/61). [BatteryMonitor](https://github.com/JKWTCN/BatteryMonitor/blob/master/src/providers/xbox/FlydigiControllerReader.cpp) получает уровень Direwolf 4 через фирменную службу, которая в этом проекте не используется.

### Диагностика Direwolf 4

Запрос состояния `HeartBeatControllerCommandXInput` формирует 15 байт `A5 10 NN 00 … 00`, где `NN` — случайный байт. Space Station отправляет эту команду через `XboxComm64.dll` и драйвер `Xbox360Filter64.sys`.

В 32-байтном ответе байт 15 равен `0x10`, байт 16 содержит код модели `0x84` (FP4), а младшие четыре бита байта 23 содержат уровень по шкале от 0 до 5. Индексы отсчитываются с нуля. Значение 1 в старших четырёх битах означает зарядку. Формат соответствует [описанию семейства XInput-команд Flydigi](https://github.com/uiltonlopes/flydigi-space-station-mac/blob/main/docs/spacestation4-analysis.md).

Фирменный драйвер возвращает ответ через порт `\XboxFilterPort`, который в установленной версии допускает одного клиента и использует [права администратора или SYSTEM](https://learn.microsoft.com/windows-hardware/drivers/ddi/fltkernel/nf-fltkernel-fltbuilddefaultsecuritydescriptor). Системные USB-интерфейсы донгла обслуживает `xusb22`, и `WinUsb_Initialize` на них не открыл канал WinUSB. Рабочий маршрут получения ответа в обычном процессе без фирменного драйвера пока не найден.

Стандартные USB-дескрипторы донгла показывают одну конфигурацию и один интерфейс: `FF:5D:01`, interrupt IN `0x81` и OUT `0x05`. Отдельного интерфейса для подключения WinUSB параллельно с XInput нет.

Системный GameInput на включённом Direwolf 4 определяет семейство Xbox 360 и возвращает `GameInputBatteryNotPresent`. Он показывает один входной отчёт и ни одного выходного или feature-отчёта.

В `driver` реализован собственный KMDF-фильтр с одним запросом чтения батареи. INF добавляет его ниже `xusb22`. Перед открытием интерфейса батареи фильтр проверяет точный USB-экземпляр Direwolf 4. Фильтр отправляет heartbeat в `0x05` и разбирает ответ на уже открытом XInput входе `0x81`; штатные входные ответы передаются драйверу XInput. Battery Monitor показывает полученный уровень по шкале Flydigi.

### Проверенный вариант с подписанным фильтром Flydigi

На ПК с установленным системным фильтром `Xbox360Filter64.sys` карточка Direwolf 4 предлагает «Включить автоопрос». После подтверждения и UAC приложение извлекает встроенный `FlydigiSample.exe` в `%SystemRoot%\System32\BatteryMonitorFlydigiSample.exe` и создаёт в Планировщике задание `Battery Monitor - Flydigi charge` от SYSTEM с интервалом в минуту. Интерфейс Battery Monitor работает с обычными правами и читает последнюю выборку из `HKLM\SOFTWARE\Battery Monitor\Flydigi`. Через 90 секунд выборка считается устаревшей. На испытанном донгле ответ уровня 4 означал 80% по шкале устройства.

Модуль проверяет наличие донгла и пропускает прямой опрос, когда запущен `SpaceStationService.exe`. Для установленной Space Station приложение умеет запрашивать список устройств через локальный канал `fcs.sock`. Разбор ответа проверен на тестовых данных. Совместная работа с запущенной Space Station и установка фирменного фильтра на чистой Windows требуют отдельной проверки.

Чтобы убрать автоопрос, завершите задание «Battery Monitor - Flydigi charge», удалите его в Планировщике и удалите файл `%SystemRoot%\System32\BatteryMonitorFlydigiSample.exe` с правами администратора. Фирменный фильтр Flydigi используется отдельно.

## Установка на Windows 11 x64

Запустите BatterySetup.exe из распакованного комплекта. Подключите донгл Direwolf 4 и включите геймпад. В карточке устройства нажмите «Установить драйвер» и подтвердите UAC. Battery Monitor скачает Xbox360Filter64.sys версии из Space Station 4.2.3.1 из каталога driver-package/flydigi-4.2.3.1 этого репозитория. Перед установкой программа сверит SHA-256 и проверит подпись средствами Windows. Фильтр регистрируется как драйвер по требованию с зависимостью от FltMgr. Затем приложение включает автоопрос. Установщик сразу запрашивает заряд. Если USB-канал ещё не готов, он сверяет экземпляр донгла с портом родительского USB-концентратора и один раз пробует переподключить этот порт программно. Если потребуется ручное переподключение, инструкция появится в карточке. Карточка автоматически обновляется при записи нового измерения.
## Профили устройств

Добавьте UTF-8 JSON-файл в `dist\devices` и перезапустите приложение. Для исходников и сборки храните профили в `devices`. Порядок карточек соответствует именам файлов.

При запуске приложение сканирует подключённые приёмники и читает публичный `catalog.json` из ветки `main` репозитория `demurez/battery-accs-info`. Сопоставление выполняется локально по VID/PID и HID Usage либо по имени USB-экземпляра игрового приёмника. Скачиваются только совпавшие JSON-профили. Они сохраняются в `%LOCALAPPDATA%\Battery Monitor\profile-cache`. При недоступности GitHub используются встроенные и ранее проверенные профили. Сетевые каталоги ограничены известными запросами чтения. Для публикации поддерживаемой модели добавьте JSON в `devices` и его селектор в `catalog.json`.

Поддерживаются `hid-output`, `airoha-ystech` и `gamepad`. Для HID-профиля укажите имя, тип значка (`mouse`, `headset`, `gamepad` или `device`), подпись подключения, VID, список PID, страницы Usage и при необходимости конкретный Usage. Числа в JSON записываются в десятичном виде. В `hid-output` задайте байты команды и смещение процента в ответе. `replyId` ограничивает первый байт ответа, а значение 256 отключает эту проверку. `powerOffset`, если задан и ненулевой, указывает байт состояния USB-питания. В `gamepad` связка VID, PID и `usbSerial` указывает точный интерфейс XUSB. Для нового семейства протоколов потребуется адаптер в коде.

## Сборка и проверка

Нужны MSVC Build Tools и Windows SDK с заголовками C++/WinRT. Запустите из PowerShell:

```powershell
.\build.ps1
```

Скрипт собирает приложение и установщик.
