# Battery Monitor

Заряд мыши VXE R1 NearLink, гарнитуры Razer Barracuda X (2021) и геймпада Flydigi Direwolf 4 в трее Windows 11 и в центре уведомлений (Win+N).

[Скачать BatteryMonitor.exe для Windows 11 x64](https://github.com/demurez/battery-accs-info/releases/latest/download/BatteryMonitor.exe)

Сохраните файл и запустите его. Профили трёх устройств уже внутри. Наведите курсор на значок в трее, чтобы увидеть проценты, или нажмите на него для подробностей.

Для Direwolf 4 приложение при необходимости предложит установить фильтр Flydigi. Space Station для этого не требуется. У Barracuda X процент заряда приблизительный.

**Сборка из исходников** — запустите `.\build.ps1` в PowerShell с установленными MSVC Build Tools и Windows SDK.
